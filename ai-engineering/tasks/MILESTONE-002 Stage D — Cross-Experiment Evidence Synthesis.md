# 4. Required Evidence Categories

Classify every cross-experiment signal as one of:

```text
REPEATED POSITIVE SIGNAL

SINGLE-EXPERIMENT POSITIVE SIGNAL

REPEATED LIMITATION

SINGLE-EXPERIMENT LIMITATION

CONTRADICTORY SIGNAL

NOT COMPARABLE

NOT TESTED
```

Definitions:

---

## REPEATED POSITIVE SIGNAL

A meaningful positive pattern independently observed in both experiments.

Example:

```text
Inspection before modification occurred
in EXP-M2-001 and EXP-M2-002.
```

This does NOT automatically prove:

```text
Procedure caused improvement.
```

It means:

```text
The procedure pattern was reproducibly observed.
```

---

## SINGLE-EXPERIMENT POSITIVE SIGNAL

Observed only in one experiment.

Example:

```text
Revision Boundary Discovery
```

observed in EXP-M2-002 but not meaningfully testable in EXP-M2-001.

Do not downgrade it to invalid.

Instead classify:

```text
Single Context Evidence
```

---

## REPEATED LIMITATION

A limitation present in both experiments.

Examples:

```text
Single executor

Single repository

No failure recovery

No dependency composition
```

Repeated limitations reduce evidence breadth.

---

## CONTRADICTORY SIGNAL

Two experiments produce meaningfully different results.

Do not force consistency.

Investigate:

```text
Task differences

Complexity differences

Execution context

Procedure interpretation
```

# 9. D. Revision Boundary

This dimension requires careful handling.

EXP-M2-001:

```text
Primary Target Only
```

may have imposed an external boundary.

EXP-M2-002:

```text
Boundary Discovery
```

was explicitly tested.

Therefore do NOT falsely classify:

```text
Boundary Discovery
```

as:

```text
Repeated Positive Signal
```

unless both experiments genuinely tested it.

Instead consider:

```text
EXP-M2-001:
Boundary behavior observed
under externally constrained scope.

EXP-M2-002:
Boundary discovery explicitly exercised.
```

Likely classification:

```text
Context-dependent evidence.
```

Explain carefully.
